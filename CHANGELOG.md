# История изменений

## 0.1a-b2 — 2026-10-25

### Новое
- Название **Hello!**, иконка, тема «ночное море».
- **Журнал на главной**: фильтры «Все / sing-box / Xray / Hello! / Ошибки», копирование, очистка, разворот на весь экран, индикатор недавних ошибок. Вкладка «Журнал» убрана из меню.
- **Автопереключение** (ядро sing-box): проверка соединения через туннель каждые 30 с; после двух неудач — замер серверов подписки и переключение на самый быстрый рабочий с проверкой, без перезапуска TUN. Метка «авто» исключает сервер из перебора. Ручной выбор сервера внутри подписки — мгновенный.
- **«Собрать логи»** — в журнале, в настройках и в трее: zip на рабочий стол с журналом, конфигами, настройками, историей переключений, версиями ядер, интерфейсами и маршрутами; секреты вырезаны.
- **Установщик** (NSIS): ярлыки на рабочем столе и в «Пуске», ядра внутри, запуск с правами администратора, русский интерфейс.
- Версии в формате `0.1a-b2`, команда `npm run set-build`.
- Настройки переносятся из прежнего «VPN Launcher».

### Исправлено
- `set ipv4 address: The object already exists` — адрес TUN теперь выбирается из свободных подсетей (конфликт с TUN NekoBox).
- Мусорные ANSI-коды (`[31m`) в журнале.
- Кнопка «Перезапустить от администратора» открывала пустое окно Electron.
- В Electron 45 бинарник не скачивается при `npm install` — добавлен отдельный шаг.

### Меньше
- В установщике только русская и английская локали Chromium, без неиспользуемых `geoip.dat`/`geosite.dat`, максимальное сжатие.

## 0.1a-b1 — 2026-10-25

Первая версия клиента (тогда «VPN Launcher») на Electron: импорт ссылок и подписок, выбор приложений (TUN sing-box + `process_name`/`process_path`), режимы «только выбранные» / «всё, кроме выбранных», ядра sing-box и Xray, трей, TCP-пинг.
