# Hello!

**VPN-клиент для Windows**

Свои серверы и подписки · раздельное туннелирование · автопереключение

## Что умеет

- **Раздельное туннелирование.** Через VPN идут только выбранные программы — или, наоборот, все, кроме них.
- **Свои серверы и подписки.** Вставьте ссылку на свой сервер или подписку от провайдера. Подписки обновляются сами, видно остаток трафика и срок действия.
- **Автопереключение.** Если сервер перестал отвечать, Hello! сам переключится на самый быстрый из рабочих.
- **Логи в один клик.** Архив для разбора проблем — без паролей, ключей и адресов серверов.
- **Не мешает другим клиентам.** Спокойно стоит рядом с NekoBox и подобными.

## Поддерживаемые протоколы

| Протокол | Транспорт и защита |
|---|---|
| **VLESS** | TCP, WebSocket, gRPC, HTTPUpgrade, XHTTP\* · TLS, Reality, Vision |
| **VMess** | TCP, WebSocket, gRPC, HTTPUpgrade · TLS |
| **Trojan** | TCP, WebSocket, gRPC, HTTPUpgrade · TLS |
| **Shadowsocks** | AEAD и Shadowsocks 2022 |
| **Hysteria2** | обфускация Salamander, прыжки портов |

Серверы добавляются ссылкой (`vless://`, `vmess://`, …) — по одной, списком или подпиской.

<sub>\* XHTTP работает через ядро Xray (переключается в настройках).</sub>

## Установка

Скачайте из [Releases](../../releases) один из файлов:

- **`Hello-Setup-<версия>-win-x64.exe`** — установщик с ярлыками на рабочем столе и в «Пуске»;
- **`Hello-<версия>-win-x64-portable.zip`** — без установки: распакуйте в любую папку и запустите `Hello.exe`.

> Установщик пока не подписан сертификатом, поэтому Windows SmartScreen может показать «Windows защитила ваш компьютер» → **Подробнее** → **Выполнить в любом случае**.

Hello! запускается с правами администратора — они нужны для TUN-интерфейса.

## Сборка из исходников

Нужен [Node.js](https://nodejs.org) 22+.

| Файл | Что делает |
|---|---|
| `run.bat` | ставит зависимости, скачивает ядра, запускает Hello! из исходников |
| `build.bat` | собирает установщик и portable-архив в `release\<версия>\` |

Оба сами запросят права администратора. Подробности — в `setup.log` / `build.log`.

Вручную:

```bat
npm install
npm run fetch-cores        :: sing-box.exe и xray.exe в bin\
npm test                   :: тесты парсера, конфигов, диагностики
npm start                  :: из терминала с правами администратора
npm run dist               :: установщик
```

## Версии

Формат — **`0.1a-b2`**: `0.1` — версия, буква — стадия (`a` альфа, `b` бета, без буквы — релиз), `b2` — номер билда, растёт с каждой раздачей.

```bat
npm run set-build -- 3          :: 0.1a-b3
npm run set-build -- 1 0.2a     :: 0.2a-b1
```

Команда обновит semver (`0.1.0-alpha.3`), версию файла (`0.1.0.3`), имя установщика и название в списке программ Windows. История — в [CHANGELOG.md](CHANGELOG.md).

## Как устроено

```
 Hello! (Electron)                          sing-box.exe
 ┌──────────────────────────┐   конфиг    ┌───────────────────────────────┐
 │ интерфейс · подписки     │ ──────────▶ │ TUN + правила process_name /  │
 │ трей · журнал · логи     │             │ process_path                  │
 │ сторож автопереключения  │ ◀─Clash API─│ selector из серверов подписки │
 └──────────────────────────┘             └──────┬───────────────┬────────┘
                                          выбранные программы   остальные
                                                 │                  │
                                           VPN-сервер (или     напрямую
                                           SOCKS → xray.exe)
```

| Путь | |
|---|---|
| `main.js` | окно, трей, IPC, подписки, уведомления |
| `src/parser.js` | разбор ссылок и подписок |
| `src/configBuilder.js` | конфиги sing-box (TUN, правила процессов, selector) и Xray |
| `src/coreManager.js` | запуск ядер, свободный адрес TUN, автопереключение |
| `src/diagnostics.js` | «Собрать логи»: zip с вырезанными секретами |
| `src/processes.js` | список запущенных программ с иконками |
| `src/store.js` | настройки в `%APPDATA%\Hello\launcher.json` |
| `renderer/` | интерфейс (HTML/CSS/JS без сборщика) |
| `scripts/` | загрузка ядер, тесты, версия |

## Планы

- **0.2a — переезд на Tauri (Rust).** Тот же интерфейс, но вместо встроенного Chromium — системный WebView2: ~10–15 МБ памяти в трее вместо ~200 МБ и установщик ~35 МБ вместо ~120 МБ. sing-box остаётся отдельным процессом с автоперезапуском, а права администратора берёт на себя служба Windows — без запроса UAC при каждом запуске.
- Поддержка новых форматов ключей и подписок.
- Кнопка «Обновить подписки» на главном экране.
